# Problem formulation
* Two balls, Ball B (Blue Ball) and Ball R (Red Ball) exists in 2D space
* The goal is to control B so that it overlaps R
* State is x_b, y_b and x_r, y_r the 2D coordinate of thw two balls
* Control input is dx_b, and dy_b, the delta of the x and y movement over time step
## Network design
Multilayer Perceptron
